# Code of Conduct

## Our Standard

Blackjack Party welcomes constructive participation from people with different backgrounds and experience levels.

Examples of helpful behavior:

- using respectful, specific language
- focusing critique on the work, not the person
- assuming good faith while still asking clear questions
- accepting maintainer decisions about project scope
- helping keep the project safe for casual browser-game use

Examples of unacceptable behavior:

- harassment, threats, or personal attacks
- discriminatory language or conduct
- sexualized language or imagery
- publishing private information without permission
- repeated off-topic, spammy, or disruptive behavior
- pushing gambling-service or real-money wagering features into this project

## Scope

This code of conduct applies in project spaces, including issues, pull requests, discussions, and other project-maintained community channels.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block accounts, or take other reasonable action when behavior does not meet this standard.

If you need to report conduct concerns, contact the repository maintainer through the repository owner profile. Do not use public issues for private conduct reports.
